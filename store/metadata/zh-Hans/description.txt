Softcap 把你的 Claude Code 和 OpenAI Codex 订阅还剩多少，直接显示在菜单栏里——不必等到事情做到一半才发现用完了。

所有订阅额度，一屏看完。你添加的每个账号，Softcap 都会读取它的五小时会话窗口和每周窗口，并把两者都摆在眼前：菜单栏里的倒计时、一次点击就打开的窗口、桌面上的小组件。

同时管理多个账号
Claude 和 Codex 的账号并排显示，有多少放多少。登录走你自己的浏览器，因此 Softcap 从不索要密码，也绝不会让你的命令行工具掉登录。不看的账号可以隐藏，其余的拖成你想要的顺序。

用完之前就告诉你
默认在 80% 和 95% 提醒，也可以改成你自己设定的阈值——每越过一次提醒一次，而不是每读取一次就提醒。免打扰时段让夜里保持安静，事后也不会补发。

菜单栏里的计时器
最接近用尽的那个额度，以及它还有多久恢复，什么都不用点。菜单栏可以显示倒计时、百分比，或者只留一个图标。

小组件
四种尺寸齐全，与窗口用的是同一行账号数据，因此两者不会对不上。

用量历史
最近一周或最近一个月的每周额度曲线，保存在你自己的 Mac 上，35 天后自动清除。

你的令牌留在原处
凭据保存在钥匙串里，绝不会被复制到偏好设置或日志中。查询用量不会发送任何提示词，也不消耗你的额度：每次读取每个账号一个请求，后台每五分钟一次，窗口打开时每分钟一次。

十种语言
阿拉伯语、孟加拉语、中文、英语、法语、印地语、印尼语、葡萄牙语、俄语和西班牙语——阿拉伯语从右向左排版。切换立即生效，无需重启，VoiceOver 可朗读整个应用。
